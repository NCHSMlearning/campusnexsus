## 📖 Overview

**CampusNexus** is a next-generation digital learning platform designed to transform educational institutions across Africa. Built specifically for **Nursing**, **TVET**, and **Higher Learning Institutions**, it provides a secure, all-in-one solution for modern education management.

**Live Demo:** [http://campusnexus.co.ke](http://campusnexus.co.ke)

---

## ✨ Key Features

### 👨‍🎓 Student Portal
- Access courses and learning materials
- Track academic progress
- Check attendance records
- View exam cards and results
- Submit assignments online

### 👨‍🏫 Lecturer Portal
- Manage classes and courses
- Grade assessments
- Create and schedule exams
- Track student performance
- Upload learning resources

### 📝 Online Examinations
- Create custom exams
- Schedule test dates
- Automatic grading
- Real-time analytics
- Anti-cheating measures

### 📍 Attendance Tracking
- QR code scanning
- Geo-location verification
- Real-time tracking
- Automated reports

### 📚 Learning Resources
- Document uploads (PDF, Word, PPT)
- Video content support
- Course materials management

### 📊 Analytics & Reports
- Performance dashboards
- Student engagement metrics
- Course completion rates

### 💰 Fee Management
- Fee structure setup
- Payment tracking
- Outstanding balances

### 🎫 Support Tickets
- Issue tracking
- Priority management
- Resolution monitoring
